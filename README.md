# Predictive-FP

This repository contains the code and dataset for the paper:

**Eadem, Sed Aliter: Investigating the Instability of Browser Fingerprinting**

## Overview

This project implements **Predictive-FP**, an adaptive fingerprinting strategy that leverages historical population-wide information to anticipate unstable fingerprinting values while ignoring ephemeral attributes (e.g., version numbers). It evaluates device re-identification using both a traditional baseline approach and the Predictive-FP approach across different timeframes.

## Dataset

The fingerprinting dataset used in the paper was collected from real users authenticating with high-value web services and is subject to strict data-sharing agreements with our industry partners. It cannot be redistributed.

The `test_data/` directory included in this repository contains **synthetic data** generated to illustrate the expected data format and allow the code to run end-to-end. The synthetic data is produced by `generate_test_data.py` and mirrors the schema of the real dataset:

- Each JSON file represents one device, named by a SHA-256 hash
- Each file contains multiple session records in JSONL format (one JSON object per line)
- Each record has the following fields:

| Field | Description | Example |
|---|---|---|
| `loginidName` | Anonymized user identifier (hash) | `"c9bbd7e8..."` |
| `cookie` | Session token (opaque random string) | `"Z42wbB9R..."` |
| `timestamp` | UTC login timestamp | `"2023-11-27 08:14:32+00:00"` |
| `fp` | Browser fingerprint object | `{...}` |

The `fp` object contains browser fingerprint attributes including `userAgent`, `http_userAgent`, `platform`, `resolution`, `avail_resolution`, `devicePixelRatio`, `webgl_vendor`, `webgl_renderer`, `webgl_parameters`, `canvas`, `font`, `pluginFeature`, `dateFeature`, `productSub`, and more.

The `pairs/` directory contains the **FP-flip knowledge base**, which consists of value transition pairs observed across sessions of the same device and used by Predictive-FP to anticipate future attribute changes. `pairs_least_5/` is a filtered version that retains only pairs observed across five or more devices.

## Installation

Install the required dependencies:
```bash
pip install tqdm
```

## Running the evaluation

To evaluate Predictive-FP and the Baseline for a given number of months:
```bash
python main.py <number_of_months>
```

For example, to run re-identification for 1 month, 2 months, ..., up to 6 months:
```bash
python main.py 6
```

### Expected results

Results on the synthetic data will differ from the paper (which uses millions of real user sessions). 

## Output files

Results are saved in `result/test_<N>m_result/` for each evaluated duration:

- **result.json**: Summarizes the performance of both approaches, including Consistent ID count/ratio (same identifier across multiple sessions), Unique ID count/ratio (distinct consistent identifiers), and All ID count (total generated identifiers).
- **baseline_changes.json**: Lists unstable attributes causing failures in the baseline approach, with per-attribute device counts.
- **predictive_changes.json**: Lists unstable attributes causing failures in the Predictive-FP approach, with per-attribute device counts.
- **id.json**: Per-device identifiers generated by both approaches.

## Browser extension

The **FP-randomizer** extension (in `FP-randomizer/`) injects controlled noise into browser fingerprints to prevent tracking over time while preserving normal website functionality. It provides:

- **Global fingerprinting control**: Enable or disable all spoofing and noise-injection mechanisms.
- **User-Agent spoofing control**: Independently toggle spoofing of the header User-Agent, `navigator.userAgent`, and `navigator.appVersion`.
- **Website allowlist**: Specify domains where spoofing is disabled so trusted sites receive unmodified fingerprints.
- **Identity lifetime management**: Configure how long a spoofed identity persists, with an option for immediate rotation.
- **Attribute-level fingerprint noise**: Perturbations to screen properties, WebGL vendor/renderer strings, font layout metrics, and canvas pixel data.

### Extension installation

Open your browser's extension settings, enable **Developer Mode**, and load the extension by selecting the `FP-randomizer/` directory.
